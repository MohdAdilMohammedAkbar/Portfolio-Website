# Portfolio Website

Personal portfolio of Mohd Adil Mohammed Akbar, Applied AI Engineer.

Static site: plain HTML, CSS and vanilla JavaScript. There is no build step and no dependencies to install.

## Files
- `index.html`: all content (hero, experience, projects, skills, achievements, contact)
- `css/styles.css`: design tokens (colors, fonts) are at the top of the file
- `js/scripts.js`: hero animation, scroll effects, contact form
- `libs/font-awesome`: icons

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` in this folder.

## Deploy
Push to GitHub and enable GitHub Pages for the main branch.
